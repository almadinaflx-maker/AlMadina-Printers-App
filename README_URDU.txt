المدینہ پرنٹرز ٹانڈہ، گجرات — Android App Project

خصوصیات:
- Home screen
- New Project
- Customer name, mobile, address
- Android Current Location permission
- Open location in Maps
- Room / Wall measurements
- Sq Ft calculation and rate
- Extra charges
- Save / View Saved Projects
- Settings / PDF branding
- Print / PDF via Android print dialog
- Data is stored locally on the phone

APK بنانے کے لیے Android Studio میں یہ فولڈر کھولیں اور Build > Build APK(s) منتخب کریں۔
